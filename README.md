# A-Frame Components

This project is an interactive 3D interface built with A-Frame, JavaScript, HTML, and CSS. It features custom A-Frame components, allowing users to manipulate 3D objects on the scene. The components are demonstrated across multiple pages, showcasing their behavior and interactivity.

Several A-Frame components have been created, allowing for enhanced control over 3D objects. Also used a GUI (Graphical User Interface) powered by the lil-gui library to dynamically change component properties.


```bash
cd a-frame-components
```

```bash
npm i
```

